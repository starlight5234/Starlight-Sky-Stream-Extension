# 🌌 Starlight-Sky-Stream-Extension
Starlight-Sky-Stream-Extension is a custom extension repository for [SkyStream](https://github.com/starlight5234/skystream).

## 🚀 Setting Up Extensions
Follow these steps to activate the providers from this repository:

1. Open **SkyStream** and navigate to **Settings**.
2. Select the **Manage Extensions** menu.
3. Click on the **Add Repository** button.
4. Enter the following Repository URL:
   ```text
   https://raw.githubusercontent.com/starlight5234/Starlight-Sky-Stream-Extension/main/repo.json
   ```
5. Tap **Add**.
6. Wait for the list to populate, then download the plugins (like **WatchiBly**).
